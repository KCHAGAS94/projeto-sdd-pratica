
# Constituição do Projeto

## Tech Stack
- Frontend: Next.js (App Router, Server Actions)
- Estilização: Tailwind CSS
- Banco de Dados: PostgreSQL
- ORM: Prisma
- Linguagem: TypeScript

## Regras Obrigatórias de Código
1. Sempre use Server Actions no Next.js para manipulação de dados.
2. Todo componente deve usar classes utilitárias do Tailwind CSS.
3. As variáveis de ambiente do banco de dados ficam no arquivo `.env` com o nome `DATABASE_URL`.
